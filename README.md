# 📈 Demand Forecasting & Prediction

A machine learning-powered demand forecasting application that transforms historical sales data into demand predictions.

## 🚀 Overview

This project uses machine learning to predict product demand based on historical data. It covers the complete workflow from data preprocessing and exploratory analysis to model training, evaluation, and deployment.

The trained model is integrated into an interactive Streamlit application, allowing users to generate demand predictions through a simple interface.

## ✨ Features

- 📊 Exploratory Data Analysis and visualization
- 🧹 Data cleaning and preprocessing
- ⚙️ Feature engineering
- 🤖 XGBoost regression model
- 📈 Model evaluation
- 💾 Saved machine learning model and encoders
- 🖥️ Interactive Streamlit application
- 🔄 End-to-end ML workflow

## 🛠️ Technologies

- XGBoost
- Matplotlib
- Seaborn
- Streamlit
